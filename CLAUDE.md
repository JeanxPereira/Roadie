# Roadie

Roadie: reverse engineering of Brutal Legend (PC) resource formats, a pure-Python decoder library
(`brutal/`), a command-line explorer (`python -m brutal`) and a Blender 5.2 extension that imports
meshes, rigs, materials, textures, morphs and animations straight from the game's bundles.

## The principle

The game is the source. `BrutalLegend.exe` (IDA 9.4) and the bundles in `Win/Packs` are the only
authorities; the old Noesis script and DoubleFine Explorer are leads, never proof. A fact is true
when a corpus gate proves it over every resource of that type, and the gate must bite: break the
fact (change an offset, drop a field) and the gate fails.

## Rules

1. Every format fact lives in the decoder's top docstring and in `docs/formats.md`, with its gate and, when it came from code, the IDA address.
2. No guessed field ships unmarked. Unknowns are named as unknown; assumptions say "assumption" and why.
3. A decoder change is done when `python check.py` passes (exit code is the verdict). Touching the addon: `python check.py --blender` and look at the render.
4. Evidence stays out of git: IDA database, decompiles, Blender, renders and extracted game data live in `.evidence/` (ignored). The repo carries scripts only. One exception: the README art in `docs/img/` (`banner.svg`, `progress.svg`, `h-*.svg`) is set in the game's fonts and emblems; it is regenerated by `tools/readme_art.py`, never hand-edited, and nothing else extracted is committed.
5. `brutal/` is stdlib-only Python 3.11 (it runs inside Blender). No numpy.
6. Only one process opens the IDA database at a time.
7. Name functions in IDA as they are understood (`python tools/ida/ida.py rename EA NAME`).
8. Space: game is Y-up right-handed; Blender conversion is `(x, y, z) -> (x, -z, y)`. Never a reflection.
9. Commits: no AI attribution of any kind.

## Tools

- `python tools/ida/analyze.py` builds `.evidence/ida/BrutalLegend.exe.i64` (≈5 min).
- `python tools/ida/ida.py strings|xrefs|decomp|imm|vtable|rename` queries it headless; `decomp EA -d N` writes the call-graph closure to `.evidence/decomp/`.
- `python tools/readme_art.py` regenerates the README art from the install (needs Pillow).
- `python tools/build_addon.py` builds `dist/brutal_legend-<ver>.zip` (addon + vendored `brutal/`).
- `sh tools/blender.sh ARGS` runs the pinned portable Blender 5.2.3 with an isolated profile, reinstalling the fresh build first.
- Release: bump `version` in `blender/brutal_legend/blender_manifest.toml`, tag `vX.Y.Z`, push; `.github/workflows/release.yml` builds, validates (`tools/ci_blender.sh`), releases and publishes the extensions repo on Pages.
- `BL_GAME_DIR` overrides the install path (default in `brutal/paths.py`).
