# Roadie

Roadie: reverse engineering of Brutal Legend (PC) resource formats, a pure-Python decoder library
(`Blender/BrutalLegend/Brutal/`), a Blender 5.2 extension that imports meshes, rigs, materials,
textures, morphs and animations straight from the game's bundles, and `roadie`, a C++ program on
OnyxSDK 2.0.0 that takes over the decoders one format at a time. Until a format has a C++ gate,
the Python decoder is its only implementation.

## The principle

The game is the source. `BrutalLegend.exe` (IDA 9.4) and the bundles in `Win/Packs` are the only
authorities; the old Noesis script and DoubleFine Explorer are leads, never proof. A fact is true
when a corpus gate proves it over every resource of that type, and the gate must bite: break the
fact (change an offset, drop a field) and the gate fails.

## Rules

1. Every format fact lives in the decoder's top docstring and in `Docs/formats.md`, with its gate and, when it came from code, the IDA address.
2. No guessed field ships unmarked. Unknowns are named as unknown; assumptions say "assumption" and why.
3. A decoder change is done when `python check.py` passes (exit code is the verdict): it builds the C++, then runs the unit tests, the C++ corpus gates, the Python/C++ parity gate and the remaining Python gates. A C++ gate replaces a Python gate only when it proves at least the same counts over the same corpus, and it is mutation-checked once (the mutation is recorded in its header). Without the game install (`BL_GAME_DIR` / `Win/Packs`), `check.py` skips the corpus and parity gates. Touching the addon: `python check.py --blender` and look at the render.
4. Evidence stays out of git: IDA database, decompiles, Blender, renders and extracted game data live in `.evidence/` (ignored). The repo carries scripts only. One exception: the README art in `Docs/Images/` (`banner.svg`, `progress.svg`, `h-*.svg`) is set in the game's fonts and emblems; it is regenerated by `Tools/readme_art.py`, never hand-edited, and nothing else extracted is committed.
5. `Blender/BrutalLegend/Brutal/` is stdlib-only Python 3.11 (it runs inside Blender). No numpy. The extension never depends on the `roadie` binary. Of Onyx's layers `Source/Brutal` links only `Onyx::Core` (nothing graphical on its include path); zlib is linked privately; OnyxSDK is consumed unpatched at `v2.0.0`.
6. Only one process opens the IDA database at a time.
7. Name functions in IDA as they are understood (`python Tools/Ida/ida.py rename EA NAME`).
8. Space: game is Y-up right-handed; Blender conversion is `(x, y, z) -> (x, -z, y)`. Never a reflection.
9. Commits: no AI attribution of any kind.

## Tools

- `cmake --preset windows` configures; `cmake --build --preset windows-debug` (or `windows-release`) builds with clang-cl and Ninja Multi-Config. Binaries land in `build/windows/<Config>/`. `ctest --preset windows-debug -LE corpus` runs the unit tests; `-L corpus` runs the corpus gates (they need the install).
- `roadie <game folder>` opens an install; verbs `types`, `ls`, `extract`, `digest`; `--game DIR` picks the install.
- `python Tools/brutal.py types|ls|info|extract|ui ...` is the Python command line, kept until the C++ verbs cover it.
- `python Tools/Ida/analyze.py` builds `.evidence/ida/BrutalLegend.exe.i64` (≈5 min).
- `python Tools/Ida/ida.py strings|xrefs|decomp|imm|vtable|rename` queries it headless; `decomp EA -d N` writes the call-graph closure to `.evidence/decomp/`.
- `python Tools/readme_art.py` regenerates the README art from the install (needs Pillow).
- `python Tools/build_addon.py` builds `dist/brutal_legend-<ver>.zip` (the extension `Blender/BrutalLegend/`, decoder included).
- `sh Tools/blender.sh ARGS` runs the pinned portable Blender 5.2.3 with an isolated profile, reinstalling the fresh build first.
- Release: bump `version` in `Blender/BrutalLegend/blender_manifest.toml`, tag `vX.Y.Z`, push; `.github/workflows/release.yml` builds, validates (`Tools/ci_blender.sh`), releases and publishes the extensions repo on Pages.
- `BL_GAME_DIR` overrides the install path (Python default in `Blender/BrutalLegend/Brutal/paths.py`, C++ default in `Source/Roadie/InstallPath.cpp`).
